Burp入门笔记

Proxy 基础抓包

这里打开Burp自带的浏览器，输入”http://example.com/“
在Burp的Proxy模块的HTTP history看到数据包（基础抓包）

数据包里可以看到的内容

数据包分为请求包（Request）和响应包（Response）

  1. 请求包（左边）：是我们发给服务器的数据
  • 请求行：请求方法 (GET/POST) + 访问路径 + 参数 + HTTP 版本
  • 请求头（Header）：Host、User-Agent、Content-Type 等一堆说明信息
  • 请求体（Body）：POST 表单参数才会有，请求头和请求体之间必须空一行，GET 请求一般没有请求体
  1. 响应包（右边）：服务器返回给我们的数据
  • 状态行：HTTP 版本 + 状态码（例如200 OK代表请求成功）
  • 响应头：服务器信息、内容类型、缓存信息等
  • 响应体：网页的 HTML 源码，就是页面真正展示的内容，可以切换 Render 标签直接预览网页效果

Repeater（重发器）

基础 GET 包修改

上图中直接右击http://example.com GET /这一行
选择Send to Repeater
切换到Repeater模块，看到：

在这里可以对GET请求进行修改：在 URL 上加 ?id=1、多参数 ?id=2&name=test
点击send后观察右边响应界面的变化

GET 转 POST 表单包：

  • 请求方法 GET → POST
  • 移除 URL 后面的所有参数
  • 在请求头末尾空一行，在空行后填写参数（请求体）
  • ⭐在Host: example.com这一行后面另起一行，增加请求头：Content-Type: application/x-www-form-urlencoded（告诉服务器这是表单格式数据）

注：右侧Response中识别响应：200 OK 代表请求成功，右侧 Render 可以预览网页，Raw 查看源码

Proxy 的 Intercept 拦截

  • 打开Proxy模块中的intercept,打开拦截总开关（intercept on）
  • 在Burp自带浏览器中访问example.com
  • 发现浏览器会转圈卡住，这是因为请求被拦住了

  • 这时切回Burp就可以看到被拦到的GET请求
  • 在拦截界面可以直接修改请求行（在GET / 后面尝试加上?id=666）
  • 之后点击Forward放行，在浏览器就可以看到界面访问

注：example.com本身不会识别我们加的？id=666 这个参数，它只是一个静态示例页面，不管你后面加什么参数，它都只会返回这一段固定提示文字：“该域名仅用于文档示例……”，所以页面样子没变，不是操作失误

  • 拦截到数据包之后，发给 Repeater 的方法：在请求内容区域右键 → Send to Repeater
    之后可以进行调试，反复测试
